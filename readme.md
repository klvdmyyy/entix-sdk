# Entix Software Development Kit

Entix3D is powerfull 3D game engine written in modern C++ with fully modular architecture.

Engine is just core functionality which provides `Result`, `Application`, `EngineMain`, `PluginManager` and so on with a lot of abstract classes. All other functionality are implemented as dynamically loaded plugins.
